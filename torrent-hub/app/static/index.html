Умный поиск

Прямой поиск по трекерам

Без базы: каждая раздача ищется непосредственно на трекере при запросе. Агрегаторы независимы и необязательны.

Как добавить собственный источник

Для RuTracker и Kinozal авторизуйся на их сайте и укажи Cookie сессии в настройках. Для уже поддерживаемого сайта можно указать своё зеркало. Для другого формата сайта нужен адаптер разбора. Совместимые JacRed/Torznab API добавляются во вкладке «Агрегаторы».

Дополнительные агрегаторы

Подключённые агрегаторы участвуют в обычном поиске автоматически. При недоступности одного другие продолжают работать. Можно добавлять JacRed, Torznab и Knaben API.

Мои TorrServer

Можно добавлять и удалять без ограничений для двух текущих устройств.

Библиотека выбранного TorrServer

Список хранится в каждом TorrServer отдельно.

Сетевые настройки

Любой совместимый HTTP или SOCKS5-прокси, с логином и паролем либо без. Локальные TorrServer не проксируются.

* Маршрут применим и к прямым трекерам, и к агрегаторам; без прямого обхода в режиме «Только через прокси».

Проверка использует поля прямо с экрана и не сбрасывает несохранённые изменения.

Временный кеш

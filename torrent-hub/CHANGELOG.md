# История изменений

## 2.0.0 — новый поисковый движок без базы

- Полностью исключены Prowlarr и его .NET-контейнер.
- Прямые адаптеры RuTor, MegaPeer и NNM-Club, протестированные по реальной выдаче.
- Настраиваемый HTTP/SOCKS5-прокси, маршрут и зеркало для каждого трекера.
- Постоянная торрент-база не создаётся: ограниченный RAM-кеш, автоочистка, кнопка очистки и статистика.
- Отдельная диагностика старых файлов Prowlarr с ручным безопасным удалением.
- Поиск через внешние агрегаторы, magnet, TorrServer и .torrent сохранены.
- Образ ARM64 собирается и публикуется заранее, не на Raspberry Pi.

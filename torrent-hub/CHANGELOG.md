# Torrent Hub — история изменений

## 1.1.2 (20.10.2026)

- Исправлены конфликты дублирующих определений Prowlarr и перенос ранее созданных файлов без удаления пользовательских данных.
- Встроенный движок и автоматическое добавление трекеров запускаются независимо от поисковых запросов, при сбое выполняются повторные попытки.
- Исправлен отсутствующий логотип в Ingress (404 /icon.png).
- Раздачи показывают крупно число сидов, размер и дату публикации.
- Сортировка перенесена над поисковой выдачей.
- При нажатии «Отправить» открывается выбор одного TorrServer.
- «Скачать .torrent»: сохранение на компьютер/телефон либо в /media/TorrentHub на Home Assistant. Если источник предоставляет только magnet, приложение честно сообщает об отсутствии оригинального .torrent.
- Прокси проверяется с сохранённой авторизацией без повторного ввода пароля.
- Проверки ARM64 перенесены на нативный runner для сокращения времени ожидания.

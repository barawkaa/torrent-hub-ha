# История изменений

## 3.0.0 — самостоятельный веб-доступ и умный поиск

- Отдельная вкладка «Умный поиск» с ползунками размера, сидов, режимом рекомендаций, строгим фильтром и сохранением параметров.
- Кнопка «Подобрать лучший вариант» из обычного поиска.
- Адаптивный интерфейс, PWA-манифест и иконка.
- Отдельный порт `8766` для Keenetic и Android с логином/паролем и защищённой сессией; Ingress HA остаётся на внутреннем `8765`.
- Структурированная диагностика по системе, трекерам, агрегаторам и TorrServer.
- Цветные показатели размера, даты и количества раздающих в результатах.
- Форма создания собственных трекеров с CSS-адаптерами и тестами.
- Необязательные RuTracker и Kinozal с авторизацией Cookie; **не проверены на реальных пользовательских аккаунтах**, по умолчанию выключены.
- Устранён сброс сохранённой Cookie при проверке введённых параметров.
- Готовый проверенный ARM64-образ GHCR; больше не требуется сборка на Raspberry Pi.
- Выпуск [подтверждён тестами GitHub Actions](https://github.com/barawkaa/torrent-hub-ha/actions/runs/39408579732).


## 2.0.0 — новый поисковый движок без базы

- Полностью исключены Prowlarr и его .NET-контейнер.
- Прямые адаптеры RuTor, MegaPeer и NNM-Club, протестированные по реальной выдаче.
- Настраиваемый HTTP/SOCKS5-прокси, маршрут и зеркало для каждого трекера.
- Постоянная торрент-база не создаётся: ограниченный RAM-кеш, автоочистка, кнопка очистки и статистика.
- Отдельная диагностика старых файлов Prowlarr с ручным безопасным удалением.
- Поиск через внешние агрегаторы, magnet, TorrServer и .torrent сохранены.
- Образ ARM64 собирается и публикуется заранее, не на Raspberry Pi.

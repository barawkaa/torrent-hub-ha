# Torrent Hub — самостоятельный поиск торрентов для Home Assistant OS

Torrent Hub — отдельное приложение Home Assistant OS: поисковый движок Prowlarr внутри контейнера, настраиваемые прямые индексаторы и опциональные JacRed/Knaben API, маршрутизация через HTTP/SOCKS5 («Прокси от Бориса»), мониторинг источников и управление несколькими TorrServer. Есть копирование magnet и отправка на выбранные серверы.

## Статус: 1.0.0-rc1

Подтверждены GitHub Actions: 20 автоматических Python-тестов, проверка JavaScript, сборка ARM64 и запуск контейнера под ARM64-эмуляцией. В стартовом тесте поднялись API Torrent Hub и встроенный Prowlarr. [Проверенный запуск](https://github.com/barawkaa/torrent-hub-ha/actions/runs/39247517618).

**Не проверено на реальном HA OS:** соединение с конкретными трекерами, работа через домашний прокси с логином и паролем, реальные magnet и загрузка на ТВ, сохранение после перезагрузки Raspberry Pi. Это кандидат для домашнего испытания, не обещание production-ready.

## Установка на Home Assistant OS (Raspberry Pi 4, aarch64)

1. В Home Assistant откройте **Настройки → Приложения → Магазин приложений → ⋮ → Репозитории**.
2. Добавьте `https://github.com/barawkaa/torrent-hub-ha` и обновите каталог.
3. Выберите **Torrent Hub** из нового репозитория, установите и запустите. Сборка может занять время из-за встроенного Prowlarr/.NET.
4. Откройте интерфейс приложения через боковую панель Home Assistant.
5. На вкладке **Прокси** задайте SOCKS5/HTTP, адрес, порт, учётные данные. Для «Прокси от Бориса» возможен адрес `192.168.1.100:2080`, но логин и пароль необходимо взять из собственного приложения и проверить. Нажмите **«Проверить введённые данные»**, затем **«Сохранить и применить к поисковику»**.
6. На вкладке **Трекеры** добавьте нужные индексаторы из встроенного каталога Prowlarr, задайте авторизацию там, где она требуется.
7. На вкладке **Диагностика** выполните проверку и убедитесь в доступности прокси, движка, трекеров и TorrServer.
8. Выполните поиск, скопируйте magnet либо выберите TorrServer и отправьте раздачу.

Предварительно добавлены TorrServer `192.168.1.148:8090` (LG-приставка) и `192.168.1.100:8090` (HA). Адреса можно изменить или добавить новые.

### Если установлен Torrent Hub 0.1.0

Старое приложение находится в другом репозитории `proxy-ot-borisa`. В Home Assistant полная идентичность приложения включает репозиторий и slug, поэтому два приложения из разных репозиториев могут существовать отдельно. Не нужно удалять **«Прокси от Бориса»**; это совершенно другое приложение. Старый Torrent Hub 0.1.0 лучше остановить, а удалять только после успешной проверки новой версии. Настройки старого Torrent Hub не переносятся автоматически.

## Прокси, источники и диагностика

- В режиме **«Только через прокси»** внешние API не переходят молча на прямое соединение. Prowlarr применяет прокси в своих настройках через API. До подтверждения режима поиск через Prowlarr блокируется.
- **«Напрямую»** разрешает прямые запросы. **«Авто»** резервирует прокси для внешних API; Prowlarr требует выбора фиксированного маршрута.
- Запросы к локальным TorrServer идут напрямую, не через VPN-прокси.
- Проверки доступности есть автоматические и по кнопке; тесты введённых параметров не должны сбрасывать несохранённые поля.
- Дополнительные внешние JacRed/Knaben-источники включаются только по выбору. Нельзя гарантировать доступность каждого внешнего сервиса или трекера.
- Раздачи, у которых трекер вернул `.torrent` вместо magnet, приложение пытается преобразовать в magnet через infohash.

## Устройство приложения

- `repository.yaml` — репозиторий приложений HA.
- `torrent-hub/config.yaml` — метаданные приложения, Ingress и параметры.
- `torrent-hub/Dockerfile` — контейнер ARM64 с Python и встроенным Prowlarr.
- `torrent-hub/app/main.py` — API, проверки, настройки и отправка на TorrServer.
- `torrent-hub/app/core.py` — нормализация, magnet, сетевые маршруты.
- `torrent-hub/app/runner.py` — контроль процессов.
- `torrent-hub/app/static/index.html` — интерфейс без сторонних CDN.
- `tests/` и `.github/workflows/verify.yml` — автоматические проверки.

## Защита и ограничения

Используйте интерфейс через авторизацию Home Assistant Ingress, не пробрасывайте наружу веб-порт. Порт Prowlarr 9696 по умолчанию не публикуется наружу. Секреты сохраняются в отдельном каталоге данных приложения (права 0600), API их не возвращает. Проверки выполняют реальные сетевые запросы, но не гарантируют наличие каждой конкретной раздачи.

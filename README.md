# Torrent Hub 3.0 — самостоятельный поиск для Home Assistant и Android

Torrent Hub — веб-приложение для Home Assistant OS на Raspberry Pi 4 (aarch64). Поиск выполняется непосредственно на трекерах, без Prowlarr, чужого JacRed и локальной торрент-базы. Публичные агрегаторы JacRed, Knaben и пользовательские Torznab API подключаются дополнительно.

## Установка и обновление

1. В Home Assistant откройте **Настройки → Приложения → Магазин приложений → ⋮ → Репозитории**.
2. Добавьте `https://github.com/barawkaa/torrent-hub-ha`, если он ещё не добавлен.
3. Обновите каталог и установите или обновите **Torrent Hub** до версии **3.0.0**.
4. Дождитесь запуска и откройте веб-интерфейс из боковой панели HA.

Сборка **не выполняется на Raspberry Pi**: Supervisor скачивает предварительно проверенный ARM64-образ `ghcr.io/barawkaa/torrent-hub-ha:3.0.0`. Для скачивания нужен доступ HA OS к `ghcr.io`. При обновлении сохраняются настройки, доступные в `/data/torrent-hub`, включая прокси, источники и TorrServer. На всякий случай перед обновлением рекомендуется создать резервную копию приложения средствами Home Assistant.

## Как пользоваться

**Поиск:** название → поиск во всех включённых прямых трекерах и дополнительных агрегаторах → выдача с количеством раздающих, размером, датой и сортировкой. Можно отключить агрегаторы или выбрать источники вручную.

**Умный поиск:** отдельная вкладка с ползунками минимального/максимального размера и количества раздающих, приоритетом качества и сохраняемыми настройками. При гибком режиме раздачи за пределами предпочтений остаются в списке как альтернативы. Кнопка **«Подобрать лучший вариант»** использует результаты обычного поиска, если они уже доступны.

**Трекеры:** RuTor, NNM-Club, MegaPeer работают без обязательного аккаунта. RuTracker и Kinozal представлены как дополнительные выключенные по умолчанию адаптеры, требуют авторизованной Cookie-сессии пользователя. Для них реализованы настройки и HTML-парсинг, **но реальный поиск с авторизованным аккаунтом не подтверждён** в публичных испытаниях. Можно менять зеркала, сетевой маршрут, включать источники и тестировать отдельные запросы.

**Свой трекер:** на вкладке «Трекеры» → «Добавить трекер» укажите адрес, шаблон поиска с `{query}`, CSS-селекторы результатов, названия, magnet и прочих метаданных. Подход предназначен для HTML-сайтов с простым поиском; сложные сайты с JavaScript, капчей или многоэтапной авторизацией потребуют специального адаптера.

**TorrServer:** введите серверы вручную, затем на карточке результата нажмите «Отправить» и выберите устройство; также доступны копирование magnet и скачивание исходного `.torrent` (если трекер его предоставляет). Можно сохранить исходный файл в браузер или `/media/TorrentHub` на HA.

**Прокси:** произвольный SOCKS5/HTTP, без зависимости от приложения «Прокси от Бориса». Маршруты настраиваются для каждого источника. В режиме только через прокси прямой обход не допускается.

**Диагностика:** группы «Система и сеть», «Трекеры», «Агрегаторы», «TorrServer»; проверка доступа и времени ответа. Кеш результатов хранится только в оперативной памяти (по умолчанию 10 минут, 350 записей), автоочищается и доступен для ручной очистки. Можно отдельно удалить оставшиеся файлы старого Prowlarr, не затрагивая новые настройки.

## Отдельный веб-доступ и Android/PWA

Помимо HA Ingress приложение публикует **локальный порт 8766**. Доступ к нему закрыт, пока вы не зададите логин/пароль в HA на вкладке **«Доступ»**.

1. Внутри интерфейса через Home Assistant откройте вкладку «Доступ» и задайте свой пароль от 12 символов.
2. Из локальной сети откройте `http://192.168.1.100:8766`, если это IP вашего Home Assistant; при необходимости измените IP согласно сети.
3. Для удалённого доступа настройте **HTTPS-домен Keenetic** с безопасным проксированием на локальный `192.168.1.100:8766`. Не публикуйте HTTP-порт напрямую в интернет без HTTPS.
4. На Android откройте защищённый HTTPS-адрес в Chrome и выберите **Добавить на главный экран / Установить приложение**. Используется тот же интерфейс и сервер поиска, отдельный APK пока не требуется.

Порт 8765 является внутренним интерфейсом Ingress и не должен публиковаться на роутере. В HA используйте штатную авторизацию Home Assistant, а на порту 8766 — независимую авторизацию Torrent Hub.

## Проверки релиза

Проверены Python-тесты, взаимодействия веб-интерфейса, нативная сборка ARM64, запуск контейнера с двумя веб-портами, закрытый до авторизации API на порту 8766, прямая поисковая выдача и magnet, отсутствие постоянной торрент-базы, работа временного кеша и анонимное скачивание образа из GHCR.

Что остаётся проверять в домашней сети: доступность каждого трекера через выбранный прокси, реальные авторизованные сессии RuTracker/Kinozal, работа Keenetic HTTPS на конкретном роутере и отправка файлов в физический TorrServer. Внешние сайты и блокировки не могут гарантировать 100% доступности.

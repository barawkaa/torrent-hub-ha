# Torrent Hub 2.0 — прямой поиск без торрент-базы

Собственный поисковик для Home Assistant OS, Raspberry Pi 4 (ARM64). В версии 2.0 **нет Prowlarr, JacRed FileDB, PostgreSQL или фоновой индексации**. При поисковом запросе Torrent Hub напрямую запрашивает сайты RuTor, MegaPeer, NNM-Club, используя выбранный HTTP/SOCKS5-прокси или прямое подключение. Внешние агрегаторы JacRed, Knaben и Torznab остаются дополнительными источниками и не участвуют в самостоятельном поиске.

## Подтверждено

В испытании ARM64-контейнера от 20.10.2026 запрос «Титаник» с `include_public=false` получил 100 раздач с RuTor, 22 с MegaPeer, 50 с NNM-Club: 171 уникальную раздачу, 100 с готовым magnet. Локальная база поиска — 0 байт. Временный кеш использовал около 87 КБ RAM, успешно очищен. Результаты зависят от доступности сайтов и могут меняться.

## Установка

Home Assistant → Настройки → Приложения → Магазин приложений → Репозитории: `https://github.com/barawkaa/torrent-hub-ha`.

Версия **2.0.0** устанавливается из готового ARM64-образа `ghcr.io/barawkaa/torrent-hub-ha:2.0.0`. Raspberry Pi **не собирает Docker-образ самостоятельно**.

При штатном обновлении остаются настройки прокси, TorrServer, дополнительных агрегаторов. Список прямых трекеров добавляется автоматически с RuTor, NNM-Club, MegaPeer.

## Настройки

- **Трекеры:** RuTor, NNM-Club, MegaPeer, их адреса/зеркала, включение, маршрут по каждому. Для незнакомого HTML-сайта требуется специальный адаптер, одного URL недостаточно.
- **Агрегаторы:** дополнительные публичные и пользовательские совместимые API JacRed, Knaben, Torznab.
- **Прокси:** собственные параметры HTTP/SOCKS5; не привязаны к стороннему VPN-приложению.
- **TorrServer:** добавление серверов; кнопки копирования magnet, отправки, скачивания оригинального .torrent в браузер или /media/TorrentHub (если источник отдаёт настоящий файл).
- **Диагностика → Временный кеш:** по умолчанию 10 минут и максимум 350 результатов; автоматическая очистка каждую минуту, текущий объём в RAM, кнопка очистки. Локальной поисковой БД нет.
- **Старые файлы:** объём данных прежнего Prowlarr показывается отдельно; удаление только по кнопке с подтверждением. Настройки Torrent Hub при этом не трогаются.

## Ограничения

Ни один сайт не гарантированно доступен: при блокировке отдельного трекера включите прокси или другое зеркало. Одновременная блокировка всех доступных трекеров технически остановит получение *новых* результатов. Постоянный каталог фильмов приложение намеренно не хранит.

Оригинальный .torrent невозможно восстановить только по magnet без получения метаданных. При ошибках трекера результаты других источников остаются доступными.

В версии 2.0 отсутствуют собственные парсеры RuTracker и Kinozal, требующие отдельной реализации и/или авторизации. Нельзя выдавать поиск по этим сайтам за работающий, пока он не реализован.

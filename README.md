# Torrent Hub — Home Assistant OS

Самостоятельное приложение поиска интернет-торрентов с подключаемыми индексаторами, HTTP/SOCKS5-прокси и несколькими TorrServer.

**Статус:** подготовка отдельного репозитория. Код 1.0.0-rc1 ожидает первичную загрузку. Пока не устанавливайте приложение: ARM64-сборка ещё не подтверждена.

После первичной загрузки кода инструкция и конфигурация приложения будут находиться в корне репозитория. Рабочий «Прокси от Бориса» остаётся независимым проектом.
